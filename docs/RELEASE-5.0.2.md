# DicodePing 5.0.2 — Stable

این نسخه ادامهٔ اصلاحات ۵.۰.۱ است و روی نسخهٔ قبلی نصب می‌شود.

- دریافت ساب در اندروید ابتدا وجود پراکسی محلی را بررسی می‌کند؛ تلاش‌های تکراری روی پراکسی خاموش حذف شدند.
- مسیر جایگزین دریافت ساب، هدرها و مهلت ۳۰ ثانیه‌ای را حفظ می‌کند. ساب اصلی از پراکسی دارای نام کاربری و رمز هم پشتیبانی می‌کند و پاسخ مسدودسازی HTML باعث تلاش روی مسیر بعدی می‌شود.
- شکست دریافت یا لغو کار، کانفیگ‌های قبلی را حذف نمی‌کند.
- اصلاحات ورود و تمدید روباه، پرچم‌ها، فهرست کشورها، وضعیت اتصال و گزارش‌های نسخهٔ ۵.۰.۱ حفظ شده‌اند.
- صفحهٔ دانلود پس از انتشار موفق به‌طور خودکار به‌روز می‌شود؛ پیش از تغییر سایت، وجود هر ۱۶ بسته و تطبیق نسخه و سورس بررسی می‌شود.
- APKها با امضای قبلی و کد نسخهٔ بالاتر بسته‌بندی می‌شوند؛ نصب تازه و ارتقا از جمله از ۵.۰.۱ در آزمون انتشار بررسی می‌شود.

کیفیت اتصال روباه به شبکه، دسترس‌پذیری سرویس و مجوز و سهمیهٔ حساب بستگی دارد. تغییرات ورود جایگزین تأیید امنیتی رسمی موزیلا نیستند.
