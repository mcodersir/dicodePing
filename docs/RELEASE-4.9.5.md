# DicodePing 4.9.5

## تغییرات نسبت به 4.9.4

- **روباه:** توزیع جریان‌ها روی چهار اتصال مستقل HTTP/2 برای کاهش اثر گیر کردن یک مسیر TCP بر همهٔ برنامه‌ها؛ تلاش دوبارهٔ محدود فقط هنگام برقراری اتصال و پیش از ارسال دادهٔ برنامه. جریان برقرارشده بازپخش نمی‌شود.
- تقسیم TLS ClientHello در ابتدای SNI، همراه با اعتبارسنجی کامل گواهی، برای مسیر VPN و درخواست‌های کنترل حساب. راه‌اندازی DNS امن برای دامنه‌های کنترل حساب نیز اعمال می‌شود تا DNS تونل، درخواست‌های خود روباه را گرفتار نکند.
- تحمل پاسخ keepalive تا ۲۵ ثانیه و توقف نوشتن تا ۶۰ ثانیه برای وقفه‌های شبکهٔ موبایل. زمان برقراری SOCKS افزایش یافته؛ مهلت برقراری به عمر انتقال داده تبدیل نمی‌شود.
- MTU مسیر روباه در دسکتاپ و رابط VPN اندروید حداکثر ۱۴۰۰ است؛ تنظیم کوچک‌تر کاربر حفظ می‌شود.
- **شروع سریع:** حداکثر ۹۰ کانفیگ پیش‌فرض در دسته‌های ۱۵تایی تست می‌شوند. با پیدا شدن مسیر سالم در یک دسته، بهترین همان دسته انتخاب و از مسیر عادی اتصال وصل می‌شود. تست همهٔ لوکیشن‌ها مانع اتصال نیست. لغو، قطع یا انتخاب دستی کاربر بر اتصال خودکار اولویت دارد.
- در اولین اجرا، درخواست اعلان و رضایت VPN پشت‌سرهم انجام می‌شوند تا اتصال خودکار دو پنجرهٔ مجوز را هم‌زمان باز نکند؛ رد اعلان مانع استفاده از VPN نیست.
- راهنمای مرحله‌ای افزودن حساب روباه با دکمهٔ باز کردن سایت رسمی ساخت حساب، ورود ایمیل/رمز و تأیید حساب. رمز ذخیره نمی‌شود.
- اصلاحات اتصال اندروید: انتخاب TUN بومی، اعتبارسنجی MTU، هماهنگی DNS با خانوادهٔ IP و بازگشت به IPv4 در دستگاهی که رابط IPv6 را نمی‌پذیرد. پاک‌سازی قواعد DNS در حالت روت نیز هماهنگ شده است.
- اصلاح خروجی WireGuard برای sing-box و تبدیل اثرانگشت TLS اختصاصی Xray به نمونهٔ سازگار هنگام استفاده از sing-box.
- **تبلیغات قابل کنترل:** فایل JSON به نام `ads.txt` در ریشهٔ ریپو؛ امکان فعال/غیرفعال کردن و انتخاب جایگاه خانه، پروفایل‌ها و روباه. کارت حامی دارای برچسب تبلیغ و لینک HTTPS است؛ پیش‌فرض خاموش، بدون اسکریپت یا رهگیری. هر ۱۵ دقیقه و هنگام باز شدن صفحه دریافت می‌شود. خطای دریافت مانع اتصال نمی‌شود. [راهنمای تنظیم](https://github.com/mcodersir/dicodePing/blob/v4.9.5/docs/ADS.md).
- بسته‌ها همان شناسه و کلید امضای قبلی را حفظ می‌کنند؛ کد مشترک APKها `45950000` است.

## هسته‌ها و ابزار ساخت

Xray دسکتاپ و کتابخانهٔ بومی اندروید: `26.10.19`؛ HEV: `2.19.1`؛ sing-box: `1.14.3`؛ mihomo: `1.19.32`؛ Aether: `2.3.0`. سه مورد آخر هنگام بررسی همچنان آخرین انتشار پایدار تأییدشده بودند. پایگاه‌های مسیریابی دسکتاپ و اندروید نیز با هش ثابت به‌روز شده‌اند.

Go `1.27.3`، Kotlin `2.4.21`، Gradle `9.8.2`، Java ساخت `27` (خروجی سازگار اندروید حفظ شده)، Python ساخت `3.15` و آخرین اصلاحات کانال .NET 10. کتابخانه‌های مستقیم با فهرست رسمی Maven/NuGet بررسی شده‌اند؛ تغییرات و استثناهای سازگاری در [گزارش وابستگی‌ها](https://github.com/mcodersir/dicodePing/blob/v4.9.5/docs/DEPENDENCIES-4.9.5.md) آمده است.

## محدودهٔ پشتیبانی و آزمون

روباه **TCP و DNS رمزگذاری‌شده** را ارائه می‌دهد. سرویس بالادستی UDP عمومی را عرضه نمی‌کند؛ ترافیک UDP پشتیبانی‌نشده از اینترنت مستقیم عبور داده نمی‌شود و برنامه‌هایی که fallback به TCP دارند از آن استفاده می‌کنند. تماس‌ها یا بازی‌های نیازمند UDP عمومی باید از کانفیگ دارای این قابلیت استفاده کنند.

آزمون‌ها شامل سالم ماندن ClientHello پس از تقسیم، اتصال TLS با نام و گواهی اصلی، چند مسیر هم‌زمان، ۸۰ جریان داده، مهلت‌های موبایل، تمدید مجوز، بازیابی اتصال بی‌پاسخ، سقف تست اولیه و تنظیم تبلیغات هستند. ساخت بومی، آزمون‌های اتصال هسته و نصب تازه/ارتقا/تعویض معماری APK پیش از انتشار کنترل می‌شوند. حساب واقعی Mozilla برای تست بلندمدت در محیط ساخت در دسترس نیست؛ موفقیت پینگ تضمین همهٔ مقصدها یا پایداری آینده نیست.
