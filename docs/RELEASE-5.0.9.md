# DicodePing 5.0.9

- اعلان انتشار جدید در شروع برنامه روی دسکتاپ و اندروید.
- ظاهر اختیاری شیشهٔ مایع (بتا) با پس‌زمینه‌های مستقل روشن و تیره.
- عنوان نوار بالای اندروید هنگام استفاده از فونت بزرگ تک‌خطی می‌ماند.
- بسته‌های اندروید با همان شناسهٔ برنامه و گواهی انتشار نسخهٔ قبلی ساخته می‌شوند. مرحلهٔ انتشار، نصب تازه و ارتقا از نسخه‌های عمومی قبلی را بررسی می‌کند.
- Xray نسخهٔ 26.11.24 از Patt، sing-box نسخهٔ 1.15.0-alpha.15 و mihomo نسخهٔ 1.19.34. در روباه، زمان بازیابی HTTP/2 با تغییر keepalive از Arman VPN 1.0.20 کوتاه‌تر شده است. تنظیمات FoxyConfig از مسیرهای قبلی دریافت می‌شوند.
- کانتینر بتای RouterOS 7 برای ARM64 و x86_64. از روباه به‌عنوان پراکسی احراز هویت‌شدهٔ TCP برای دستگاه‌های LAN استفاده می‌کند. راهنمای روتر در صفحهٔ دانلود منتشر می‌شود.
- داده‌های GeoIP و GeoSite دسکتاپ و اندروید با نسخه‌های تأییدشدهٔ ۲۷ نوامبر تازه شده‌اند.
