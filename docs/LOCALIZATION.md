# Localization

Localization maintenance and new DicodePing translation contributions: [mcodersir](https://github.com/mcodersir).

The Android and desktop resource systems use English fallback for missing strings. The 5.0.3 language picker includes Persian, English, Arabic, Turkish, Bakhtiari Luri, Kurdish (Kurmanji), Pashto, simplified/traditional Chinese and Japanese, alongside existing upstream languages. Newly selectable locales without a complete resource set currently fall back to English. Full native translations of all screens are NOT complete in this change.

Existing upstream translations and their copyright/license attribution remain intact. New contributions follow the project license; this attribution does not assert exclusive rights over inherited translations.
