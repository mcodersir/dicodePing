# DicodePing 5.0.6 برای اندروید

- این نسخه برای گزارش رد شدن بستهٔ ARM64 هنگام ارتقا روی Redmi Note 13 Pro+ 5G با اندروید ۱۶ آماده شده است.
- فایل APK مستقیماً از خروجی امضاشدهٔ ابزار ساخت اندروید منتشر می‌شود. شناسهٔ برنامه و کلید امضا حفظ شده و کد نسخه به 55000600 افزایش یافته است.
- بررسی انتشار شامل نصب تازه، ارتقا از APKهای عمومی 5.0.3 و 5.0.5، و تغییر بین ARM64 و Universal با حفظ داده‌هاست. آزمون نصب‌کنندهٔ بومی روی شبیه‌ساز انجام می‌شود.
- برای دسکتاپ، [نسخهٔ 5.0.5](https://github.com/mcodersir/dicodePing/releases/tag/v5.0.5) را دریافت کنید.
