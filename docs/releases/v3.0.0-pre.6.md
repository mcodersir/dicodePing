# dicodePing 3.0.0-pre.6

این پیش‌انتشار روی اتصالِ واقعاً تأییدشده، پینگ هم‌زمان در هر چهار خانوادهٔ انتشار، و رابط کاربری روشن‌تر تمرکز دارد.

## تغییرات اصلی

- در Windows، Linux و macOS، اتصال فقط پس از یک درخواست HTTP واقعی از طریق SOCKS محلیِ همان پروفایل «متصل» اعلام می‌شود. بازشدن صرفِ پورت دیگر کافی نیست.
- پینگ واقعی دسکتاپ از ۲۴ worker محدود استفاده می‌کند؛ همهٔ پروفایل‌های درخواست‌شده نتیجه می‌گیرند و UI برای tail یک timeout کاذب نشان نمی‌دهد.
- در Android، پینگ TCP سریع از timeout جداگانهٔ یک‌ثانیه‌ای استفاده می‌کند و probe واقعی Xray تا ۱۲ worker محدود هم‌زمان دارد؛ نتیجهٔ هر ردیف در لحظه ثبت و مرتب می‌شود.
- سقف خاموش ۸۰ پروفایل حذف شد؛ انتهای فهرست دیگر بدون تست unreachable علامت نمی‌خورد و برای هر پروفایل نتیجهٔ واقعی یا شکست صریح ثبت می‌شود.
- تست سریع پینگ برای همهٔ پروفایل‌های قابل‌تست با workerهای موازی اجرا می‌شود؛ دیگر هر سرور منتظر پایان تست قبلی نمی‌ماند.
- در Android، فیلتر TCP و probe واقعی Xray هر دو bounded و هم‌زمان هستند و نتیجهٔ هر ردیف همراه پیشرفت تست ثبت می‌شود.
- پروفایل‌های شبکهٔ خاص که تست TCP برایشان مناسب نیست، مستقیماً با بررسی واقعی ترافیک آزمایش می‌شوند و حذف اشتباه نمی‌شوند.
- انتخاب سرور و اتصال به هر ردیف در میانهٔ تست فعال است؛ تست پینگ اتصال دستی کاربر را قفل نمی‌کند.
- تست واقعی پروفایل‌ها با یک pool محدود native انجام می‌شود تا سرعت بالا برود و فشار بی‌مورد روی دستگاه ایجاد نشود؛ راهبرد worker از الگوی RealPingWorker در PattNG الهام گرفته شده، اما پیاده‌سازی و نام‌گذاری dicodePing مستقل مانده است.

## بازطراحی رابط کاربری

- صفحهٔ سرورها از نو با چیدمان مینیمال و قابل‌فهم ساخته شد.
- کارت‌ها، جستجو، دکمه‌ها و نشانگرها گوشه‌های گرد و فاصله‌گذاری منظم دارند.
- بخش خلاصه، جستجو، فیلتر منبع، عملیات اصلی و فهرست سرورها سلسله‌مراتب واضح‌تری دارند.
- وضعیت تست سریع و بررسی واقعی جداگانه و با شمارندهٔ زنده نمایش داده می‌شود.
- پس از اتصال دسکتاپ، تأخیر تأییدشدهٔ واقعی همان لحظه در کارت اتصال نمایش داده می‌شود؛ دکمه‌ها و وضعیت‌ها تنها پس از عبور ترافیک واقعی سبز می‌شوند.
- دکمهٔ دسکتاپ و متن Android صراحتاً real/parallel بودن تست را نشان می‌دهند و نتیجهٔ نهایی تعداد پاسخ‌گوها را گزارش می‌کند.
- دکمهٔ اتصال هر ردیف و اتصال سرور انتخاب‌شده در زمان تست در دسترس باقی می‌مانند.

## پایداری و اعتبارسنجی

- مرتب‌سازی و ذخیره‌سازی پس از پایان تست با نتیجهٔ نهایی واقعی هماهنگ می‌شوند.
- زمان انتظار تست سریع محدود و هم‌زمانی آن bounded است تا سرورهای قطع‌شده سریع کنار گذاشته شوند.
- اعتبارسنجی منبع، API، پروژهٔ Android، مراجع ناخواسته، workflow و تست‌های انتشار اجرا می‌شوند.
- خروجی‌های Windows x64، Linux x86_64، macOS arm64، macOS x86_64 و Android universal در GitHub Actions ساخته می‌شوند.

این نسخه برای تست میدانی منتشر شده است. در صورت مشاهدهٔ رفتار غیرعادی، گزارش لاگ و نوع پروفایل را همراه مشکل ارسال کنید.
