# dicodePing v3.0.0-pre.1 (Pre-release)

> **Pre-release** — This is a pre-release version with new networking architecture.

## What's New

### v2rayN-based Networking Stack

Version 3 replaces the legacy Python-based networking wrapper with a proper
v2rayN integration layer. The networking implementation now directly wraps the
bundled v2rayN C# library (v2rayN-7.24.5) instead of providing a Python
reimplementation of Xray core operations.

- **New `v2rayN/integration/` package**: Clean integration layer that replaces
  the legacy networking code in `dicodePing/net.py`, `xray.py`, and
  `connection_manager.py`.
- **Core management**: Download, verification (SHA-256 pinning), and lifecycle
  management of Xray, Wintun, Aether, Usque, and Psiphon cores.
- **Connection lifecycle**: TUN mode setup, route management, and startup
  verification through TUN traffic detection.

### Modern UI Redesign

A completely redesigned modern interface using PySide6 Qt:

- **Card-based layout**: Clean surface treatments with subtle shadows and
  rounded corners.
- **Dark/light theme**: Full theme support via `ThemeManager` with smooth
  transitions.
- **Modern components**: `ServerCard`, `ConnectionPanel`, `StatusBar`,
  `SidebarNav`, and `DashboardView`.
- **Responsive design**: Layout adapts to window resizing and platform
  conventions.

### Preserved Features

The following features are kept from v2:

- Subscription source: `https://raw.githubusercontent.com/mcodersir/DicodeConfigChecker/refs/heads/main/sub.txt`
- Protocol parsing: vless, vmess, trojan, ss (via `protocols.py`)
- Server discovery and scoring: `ServerService` with `build_and_save`,
  `refresh_saved`, `auto_candidates`, and `best_server`.
- Connection verification: TCP prefilter, geo resolution, and real HTTP
  probes through Xray SOCKS.
- Security assessment: Per-server config security scoring.
