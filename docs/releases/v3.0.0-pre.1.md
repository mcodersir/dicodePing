# dicodePing 3.0.0-pre.1

Version 3 introduces the production client architecture and a completely redesigned interface.

## Highlights

- New desktop UI built around connection status, profiles, routing/DNS, Scanner and runtime logs.
- Primary dicodePing subscription source remains authoritative.
- Desktop profile parsing, configuration generation, core lifecycle, real latency, system proxy and TUN are handled through the ServiceLib-based runtime host.
- Android uses the same product architecture with its platform-native Xray bridge.
- Windows, Linux, macOS arm64/x86_64 and Android universal packages are release targets.
- Version 3 uses an isolated state namespace for deterministic profile and runtime state.

## Pre-release status

This build is intentionally marked pre-release. Platform packaging is gated by validation and runtime smoke checks in the release workflow.
