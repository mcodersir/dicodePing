# dicodePing v1.9.0-rc.5

RC5 focuses on scanner reliability, responsive UI, subscription lifecycle consistency and safe cross-platform disconnects.

## Highlights

- The scanner waits for the real connection worker result instead of a fixed 20-second blind poll.
- Scanner progress and metrics wrap cleanly on narrow windows.
- Scanner output is a single local source named `SUB`; every scan replaces it atomically.
- The saved `SUB` source is immediately visible under Servers and can be removed from Settings > Sources.
- Desktop disconnect and application shutdown wait for Qt workers and the native core to finish.
- Sidebar alignment follows RTL/LTR direction with minimal selected-state styling.
- Android targets API 36, publishes only 64-bit ABIs and serializes JNI lifecycle calls.
- The Android release pipeline validates 16 KB APK zip alignment before publishing.
