# dicodePing 3.0.0-pre.2

این پیش‌انتشار، هسته و تنظیمات کامل‌تر را با رابط کاربری خطی و سبک‌تر دیکد پینگ یکپارچه می‌کند.

## قابلیت‌های جدید

- انتخاب هستهٔ ترجیحی بین حالت خودکار، Xray و sing-box از صفحهٔ Routing & DNS.
- کنترل واقعی TUN، مسیریابی خودکار، Strict route، MTU و پروکسی سیستم از یک صفحهٔ تنظیمات.
- تنظیم DNS با سه راهبرد و ترجیح IPv4/IPv6، همراه با ذخیرهٔ پایدار تنظیمات.
- نمایش هستهٔ در حال اجرا، وضعیت اتصال، تاخیر واقعی و آمار لحظه‌ای دریافت/ارسال.
- مدیریت پروفایل‌های Subscription با شناسهٔ پایدار، علاقه‌مندی و نگه‌داشتن نتایج Scanner پس از تازه‌سازی.

## بهبودهای رابط و پایداری

- ظاهر خطی‌تر و منظم‌تر: مرزهای یک‌پیکسلی، گوشه‌های کم‌گرد، ردیف‌های فشرده و سلسله‌مراتب خواناتر.
- جداسازی کامل رابط از فرایند runtime؛ ساخت کانفیگ، lifecycle، DNS، Routing و Real Ping در CoreHost انجام می‌شود.
- کنترل‌های ایمن‌تر برای payloadهای Subscription و Scanner و ثبت گزارش‌های قابل‌بررسی در صفحهٔ Logs.
- نسخهٔ اندروید با build شمارهٔ جدید و خروجی universal امضا‌شده منتشر می‌شود.
- اعتبارسنجی منبع، تست API، smoke test هسته و build چهارپلتفرمی در GitHub Actions اجباری است.

## خروجی‌ها

- Windows x64
- Linux x86_64
- macOS arm64 و x86_64
- Android universal

## وضعیت پیش‌انتشار

این نسخه برای تست میدانی منتشر شده است. برای استفادهٔ روزمره، تنظیمات TUN و پروکسی سیستم را با توجه به مجوزهای سیستم‌عامل بررسی کنید.
