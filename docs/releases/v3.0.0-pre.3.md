# dicodePing 3.0.0-pre.3

این پیش‌انتشار، رابط اندروید را به‌طور کامل بازطراحی می‌کند تا تجربهٔ اصلی روی پروفایل‌ها و اتصال سریع متمرکز باشد.

## تغییرات اصلی

- صفحهٔ اصلی اندروید کاملاً با فهرست پروفایل‌ها جایگزین شد؛ صفحهٔ خانه و نوار ناوبری قبلی حذف شدند.
- اتصال و قطع اتصال از طریق دکمهٔ شناور همیشه در دسترس است و وضعیت فعال، در حال اتصال، آماده و خطا را در نوار بالا نشان می‌دهد.
- منوی بالایی برای پروفایل‌ها، اسکنر، تنظیمات و اطلاعات برنامه اضافه شد.
- جستجو، فیلتر منبع، تازه‌سازی، تست واقعی، نمایش تأخیر، علاقه‌مندی و اتصال به پروفایل انتخاب‌شده حفظ و در چیدمان فشرده‌تر قرار گرفتند.
- ردیف‌های پروفایل تخت‌تر و خواناتر شدند و اطلاعات موقعیت، تأخیر، کیفیت، امنیت و حجم مصرفی را بدون کارت‌های بزرگ نمایش می‌دهند.

## قابلیت‌ها و پایداری

- منطق اتصال VPN، تست واقعی ترافیک، مدیریت Subscription و هسته‌های Xray/sing-box بدون تغییر مخرب در پشت رابط جدید حفظ شد.
- تنظیمات هستهٔ ترجیحی، TUN، DNS، مسیریابی، MTU، پروکسی سیستم و گزارش‌ها در نسخهٔ اندروید و دسکتاپ همچنان در دسترس‌اند.
- نسخهٔ اندروید به build شمارهٔ ۷۲ ارتقا یافت و خروجی universal برای معماری‌های arm64-v8a، armeabi-v7a و x86_64 تولید می‌شود.
- نام برنامه، شناسهٔ محصول، متن‌های قابل مشاهده و فایل‌های خروجی با برند `dicodePing` یکپارچه هستند.

## اعتبارسنجی

- اعتبارسنجی منبع، API، پروژهٔ اندروید، مراجع ناخواسته، workflow و تست‌های انتشار اجرا می‌شوند.
- build دسکتاپ ویندوز، smoke test CoreHost و build اندروید قبل از انتشار بررسی می‌شوند.
- خروجی‌های Windows x64، Linux x86_64، macOS arm64، macOS x86_64 و Android universal در GitHub Actions ساخته می‌شوند.

این نسخه برای تست میدانی منتشر شده است. پیش از استفادهٔ روزمره، مجوز VPN و رفتار پروفایل‌های واردشده را بررسی کنید.
