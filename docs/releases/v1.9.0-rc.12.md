# dicodePing v1.9.0-rc.12

## فارسی

RC12 مشکل اصلی دریافت کانفیگ‌های تلگرام را برطرف می‌کند. اسکنر در هر چهار پلتفرم فقط از آدرس استاندارد `https://t.me/s/<channel>` استفاده می‌کند و دیگر هیچ درخواست یا fallback به `telegram.me` ندارد.

| بخش | تغییر |
|---|---|
| منبع تلگرام | فقط `t.me/s/<channel>`؛ redirect خارج از `t.me` مسدود است |
| سرعت Android | صف ثابت Worker با حداکثر ۸ درخواست، اتصال‌های Keep-Alive و بدون Retry پنهان |
| توقف زودهنگام | پس از بررسی حداقل ۳۶ کانال و رسیدن به ۱۸۰ کانفیگ یکتا، دریافت پایان می‌یابد |
| Progress | پیشرفت بر اساس ترکیب تعداد کانال‌های بررسی‌شده و تعداد کانفیگ‌های هدف محاسبه می‌شود |
| پایداری | لغو Coroutine دوباره پرتاب می‌شود، درخواست‌های شبکه Cancel می‌شوند و Progress عقب نمی‌رود |
| دسکتاپ | دریافت موازی ۱۲ Worker، Timeout کوتاه‌تر و Progress مرحله‌ای ۵–۴۵ و ۵۰–۹۵ درصد |
| خروجی | نامزدها پیش از قطع VPN ذخیره می‌شوند؛ سپس تست واقعی Xray و جایگزینی منبع ثابت `SUB` انجام می‌شود |

### روند اسکن

1. اتصال VPN تأییدشده از صفحه خانه
2. پیش‌سنجی دسترسی `t.me`
3. دریافت موازی کانال‌های رتبه اول و دوم
4. ذخیره اتمیک نامزدهای خام
5. قطع کامل VPN اولیه
6. تست واقعی هر کانفیگ با Xray
7. ذخیره نتایج سالم در تنها منبع `SUB`

## English

RC12 fixes the Telegram collection path. The scanner now uses only the canonical `https://t.me/s/<channel>` endpoint on all four platforms; there is no request or fallback to `telegram.me`.

| Area | Change |
|---|---|
| Telegram source | `t.me/s/<channel>` only; cross-host redirects are rejected |
| Android speed | Fixed worker queue with up to 8 requests, connection reuse and no hidden retry |
| Early completion | Stop after at least 36 channels once 180 unique candidates are collected |
| Progress | Progress combines completed-channel work and the candidate target |
| Stability | Coroutine cancellation is propagated, HTTP calls are cancellable and progress never moves backwards |
| Desktop | 12 bounded workers, shorter timeout and phase-weighted progress |
| Output | Raw candidates are committed before VPN shutdown, then Xray performs real isolated probes and replaces the single `SUB` source |
