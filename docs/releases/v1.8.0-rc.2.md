# dicodePing v1.8.0-rc.2 — Responsive UI release candidate

> Pre-release / نسخهٔ آزمایشی پیش از انتشار پایدار

## فارسی

این نسخه بازطراحی رابط کاربری را بدون تغییر در قراردادهای هستهٔ اتصال ارائه
می‌کند. فارسی برای نصب‌های جدید پیش‌فرض است؛ انتخاب صریح قبلی کاربر حفظ می‌شود.
تم‌های «سیستم، روشن، تیره»، حالت کاهش حرکت و سه کلاس اندازهٔ پنجره اضافه شده‌اند.

### ۲۴ اصلاح عملی UI/UX

1. رفع بریده‌شدن ستون اتصال به‌علت اشتباه گرفتن ستون Pin و Action.
2. تبدیل جدول سرورها به کارت در پنجره‌های Compact.
3. حفظ Ping، Pin و Action در نمای Medium.
4. جلوگیری از فشرده‌شدن عنوان و توضیح Servers کنار نوار عملیات.
5. چیدمان چندردیفه/عمودی عملیات در عرض کم.
6. حذف تب افقی بریده‌شوندهٔ Settings.
7. افزودن ناوبری دسته‌ای کناری Settings در Medium/Expanded.
8. افزودن انتخاب‌گر دسته‌ای Settings در Compact.
9. حذف هم‌پوشانی نقاط مراحل Scanner.
10. افزودن نام واقعی هر مرحله به stepper.
11. عمودی‌شدن stepper در Compact.
12. حذف placeholder مبهم «Scanner • date».
13. افزودن design token مرکزی برای spacing/radius/breakpoint.
14. تعریف breakpointهای قطعی 900 و 1180 پیکسل.
15. حفظ حداقل پنجرهٔ قابل استفادهٔ 680×480.
16. افزودن تم System در دسکتاپ.
17. اعمال فوری پیش‌نمایش تم.
18. افزودن گزینهٔ Reduce motion.
19. افزودن متن دسترس‌پذیر به کارت‌های سرور.
20. migration یک‌بارهٔ فارسی با حفظ انتخاب صریح English.
21. بازگرداندن Scanner حذف‌شده از layout تبلت Android.
22. افزودن navigation rail برای Android Expanded (≥840dp).
23. افزودن window-size class زمان اجرا برای Android.
24. حذف transition غیرضروری در Android Compact.

Android اکنون Compact زیر 600dp، Medium از 600 تا 839dp و Expanded از 840dp
را با resource qualifier و تشخیص زمان اجرا پوشش می‌دهد. نسخهٔ Android
`versionCode 33` و شناسهٔ انتشار `1.8.0-rc.2` است.

## English

This candidate redesigns presentation without changing the connection-core
contracts. New installs default to Persian while an explicit previous English
choice is preserved. Desktop now has deterministic Compact/Medium/Expanded
layouts, server cards on compact windows, category navigation in Settings, a
semantic Scanner stepper, System/Light/Dark themes and reduced motion.

Android restores Scanner on medium devices, adds an expanded navigation rail,
and shares runtime size classes with the resource breakpoints. The connection,
probe, scanner and Xray state machines are intentionally unchanged.
