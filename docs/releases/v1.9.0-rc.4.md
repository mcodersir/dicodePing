# dicodePing v1.9.0-rc.4 — Legacy-style multi-platform packages

این Hotfix بسته‌بندی نسخه 1.9.0 RC4 را به همان ساختار انتشار نسخه 1.8.0 RC4 برمی‌گرداند، بدون حذف اصلاحات اتصال و اسکنر RC3/RC4.

## خروجی‌ها

- `dicodePing-v1.9.0-rc.4-windows-x64.exe`
- `dicodePing-v1.9.0-rc.4-linux-x86_64.tar.gz`
- `dicodePing-v1.9.0-rc.4-macos-arm64.dmg`
- `dicodePing-v1.9.0-rc.4-macos-x86_64.dmg`
- `dicodePing-v1.9.0-rc.4-android.apk`

فایل‌های Aether و WARP/Usque مانند انتشارهای قبلی به‌صورت Core مستقل برای Windows، Linux و macOS منتشر می‌شوند. هر آرشیو قبل از انتشار با SHA-256 ثابت بررسی می‌شود.

## مدل ساخت

- Windows: PyInstaller `onefile + windowed` با Xray و Wintun داخلی.
- Linux: PyInstaller `onefile` داخل آرشیو portable.
- macOS: اپلیکیشن `.app` داخل DMG؛ دو معماری Apple Silicon و Intel.
- Android: فقط APK استاندارد Release با keystore مالک پروژه امضا می‌شود.
- خروجی‌های دسکتاپ نیازمند گواهی امضای ناشر نیستند و Workflow هیچ secret امضای Windows/macOS/Linux درخواست نمی‌کند.

## اصلاحات حفظ‌شده

- رفع ناسازگاری `core_options` در Xray.
- اتصال Aether و WARP/Usque با گزینه‌های معتبر CLI.
- ذخیره انتخاب هسته و تنظیمات.
- وضعیت اتصال و Progress UI.
- اسکنر چندمرحله‌ای، لاگ هایلایت‌شده، اندازه‌گیری سرعت دریافت و تست.
- کاهش فشار روی Event Loop و جمع‌کردن Workerها هنگام توقف.
