# dicodePing v3.0.0-rc.1 (Release Candidate 1)

> **Release Candidate 1** — Major Version 3 release featuring the v2rayN networking stack, redesigned modern interface, default subscription auto-fetching, and Auto-Connect mode.

## What's New

### v2rayN-based Networking Architecture

Version 3 RC1 replaces the legacy networking implementation with the v2rayN client architecture. The networking layer directly wraps the core management and connection engine of v2rayN (v2rayN-7.24.5).

- **New `v2rayN/integration/` package**: Clean integration layer that replaces legacy networking code.
- **Core management**: Download, verification (SHA-256 pinning), and lifecycle management of Xray, Wintun, Aether, Usque, and Psiphon cores.
- **Connection lifecycle**: TUN mode setup (`dicodePing-TUN-v3`), system proxy routing, and data plane latency verification.

### Default Subscription Auto-Fetch & Auto-Connect Mode

- **Default Subscription Source**: Automatically configured with primary subscription URL (`https://raw.githubusercontent.com/mcodersir/DicodeConfigChecker/refs/heads/main/sub.txt`).
- **Auto-Fetch on Launch**: Auto-populates available server profiles on startup if no servers are currently saved.
- **Auto-Connect ("اتصال خودکار")**: Dynamic candidate selection (`ServerService.best_server()`) ranks and selects the lowest-latency, highest-security server and connects instantly.

### Redesigned Modern Interface

- **PySide6 Qt GUI**: Completely modernized user interface with surface treatments, dark/light theme switching (`ThemeManager`), `ServerCard`, `ConnectionPanel`, `StatusBar`, and `DashboardView`.
- **RTL Vazirmatn Font**: Native Persian RTL language layout and font integration.
- **Zero v2rayN User Branding**: All user-visible titles, labels, headers, and logs are 100% branded as `dicodePing`.

## Compatibility

- Windows 10 1809+
- Linux (Ubuntu 22.04+)
- macOS 12+ (Intel and Apple Silicon)
- Android 7.0+ (arm64-v8a, armeabi-v7a, x86_64)
