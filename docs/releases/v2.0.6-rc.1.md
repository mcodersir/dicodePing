# dicodePing v2.0.6-rc.1 — پیش‌انتشار پایداری اتصال

این نسخه آزمایشی روی چهار خروجی Windows، Linux، macOS و Android متمرکز است و سه مشکل اصلی را برطرف می‌کند: برقرار نشدن اتصال، خطای گواهی TLS در بسته macOS و کندی مسیر پینگ عادی.

## اصلاحات اصلی

- زنجیره گواهی قابل‌حمل `certifi` به هر سه بسته PyInstaller افزوده شد؛ اعتبارسنجی TLS همچنان کاملاً فعال است و هیچ حالت ناامن یا `CERT_NONE` استفاده نمی‌شود.
- دانلود ساب روی GitHub API، Raw GitHub و jsDelivr از یک TLS context مشترک و قابل‌اعتماد استفاده می‌کند.
- در دسکتاپ، DNS فقط یک‌بار حل می‌شود و پینگ واقعی Xray و موقعیت جغرافیایی هم‌زمان اجرا و به‌صورت زنده در جدول نمایش داده می‌شوند.
- endpointهای مرده قبل از ساخت process سنگین Xray با TCP فیلتر می‌شوند.
- در Android، پینگ عادی دو‌مرحله‌ای شد: TCP موازی سریع و سپس تأیید ترافیک واقعی Xray فقط برای گزینه‌های زنده.
- در Android، پینگ و geo هم‌زمان اجرا می‌شوند و `PingProbe` نیز TCP/ICMP را به‌صورت موازی انجام می‌دهد.
- حلقه مسیریابی VPN در حالت allowlist رفع شد؛ پردازش خود برنامه و هسته Xray دیگر داخل VPN خودش قرار نمی‌گیرد.
- پیکربندی TUN دسکتاپ دیگر با `sendThrough` به IP موقتی یک رابط قفل نمی‌شود و انتخاب رابط خروجی را به Xray می‌سپارد.
