# dicodePing v1.9.0-rc.15

## Android crash fix

- Fixed the startup/background crash caused by passing an empty or scheme-less subscription address directly to `Request.Builder.url()`.
- Subscription URLs are trimmed, safely parsed as HTTP/HTTPS and upgraded to `https://` when only a hostname/path was saved.
- Invalid legacy custom sources are removed during settings migration; a corrupted built-in source is restored automatically.
- Revision checks now return an empty result for invalid addresses instead of cancelling the Main coroutine and terminating the app.

## Native connection cores inside the APK

- Android `versionCode` is now **50** and `versionName` is **1.9.0-rc.15**, so Android installs this package as a real update instead of reusing RC14.
- `build_apk.sh` itself prepares Aether 1.4.0 and Usque 4.2.1 for `arm64-v8a` and `x86_64`; the release workflow cannot accidentally skip this stage.
- The build also downloads and verifies the official libv2ray AAR, then inspects the final APK ZIP.
- Release validation requires these files for both ABIs:
  - `libgojni.so`
  - `libaether.so`
  - `libusque.so`
- ELF architecture, size, SHA-256 and the embedded `assets/bundled_cores.json` manifest are verified before the Android artifact is uploaded.
- Native executables are extracted by PackageManager and launched from `applicationInfo.nativeLibraryDir`.

## Connection flow

1. Select Aether or WARP in Settings.
2. Return to Home and press Connect.
3. The foreground VPN flow prepares/registers the selected core, waits for its local SOCKS endpoint and verifies real HTTP traffic.
4. HTTP/2 fallback remains available when the primary MASQUE transport fails.


## Dirty-workspace deployment fix

- The deploy script now removes a stale `src/main/.../AndroidTetheringController.kt` copied from older extracted RC folders before local validation.
- Direct Windows and Unix APK builds run the same workspace cleanup before Gradle.
- The cleanup is guarded: the main-source copy is deleted only when both intended `standard` and `rooted` flavor implementations exist.
- Regression coverage recreates the contaminated folder layout and verifies that only the stale main-source class is removed.

## Release pipeline

- New immutable tag: `v1.9.0-rc.15`.
- New Android artifact: `dicodePing-v1.9.0-rc.15-android.apk`.
- The workflow fails before publishing if any required native core is absent from the final APK.
