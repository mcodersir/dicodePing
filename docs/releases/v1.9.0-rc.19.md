# dicodePing v1.9.0-rc.19

RC19 makes desktop latency testing honest and understandable.

## Desktop scanner and server list

- Every configuration is measured exactly once with a TCP handshake to its endpoint.
- Every supported configuration is independently measured once with a real HTTP request through its exact Xray outbound.
- TCP reachability never marks a proxy healthy; only the Xray data-plane test does.
- TCP and Xray values are persisted separately and shown in separate colored columns/cards.
- The desktop server list has Android-style rounded latency badges and clearer responsive behavior.
- Scanner logs and exported history include both `tcp_ms` and `xray_ms`.

## Platforms

The existing full-device TUN connection path remains enabled on Windows, Linux and macOS. Android packaging and embedded-core validation remain unchanged except for the RC19 version bump.
