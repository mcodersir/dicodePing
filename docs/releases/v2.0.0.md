# dicodePing 2.0.0 — انتشار پایدار

انتشار پایدار سری 2.0 با تمرکز بر نمایش صحیح فارسی، بازبینی واقعی نتایج اسکنر و رابط مینیمال‌تر در چهار پلتفرم.

## فونت فارسی قطعی

- Vazirmatn نسخه 33.0.3 در زمان Build دریافت و با SHA-512 رسمی npm کنترل می‌شود.
- Regular، Medium و Bold داخل هر بسته نهایی قرار می‌گیرند.
- Windows، Linux و macOS فونت را از بایت‌های داخلی بسته در Qt ثبت می‌کنند.
- تست Startup بسته‌بندی‌شده باید دقیقاً `font_family=Vazirmatn` گزارش کند.
- Android فونت را به‌صورت محلی از `res/font` بارگذاری می‌کند و به Google Fonts یا وجود فونت روی دستگاه وابسته نیست.

## اسکنر

- بعد از Commit اولیه SUB، همان رکوردهای ذخیره‌شده یک بار دیگر بررسی می‌شوند.
- دسکتاپ یک TCP handshake و یک Xray HTTP probe واقعی برای هر سرور اجرا می‌کند.
- Android یک Xray outbound probe واقعی برای رکورد ذخیره‌شده اجرا می‌کند.
- IP و موقعیت سرورها با Force Refresh دوباره دریافت می‌شود.
- نتایج نهایی شامل پینگ، وضعیت و موقعیت به‌صورت اتمیک ذخیره می‌شوند.

## رابط کاربری

- کارت‌ها و کنترل‌ها تخت‌تر و کم‌حاشیه‌تر شده‌اند.
- فاصله‌ها و ارتفاع دکمه‌ها در نمایشگرهای کوچک متعادل‌تر شده‌اند.
- فهرست سرور و نشانگرهای کیفیت خواناتر هستند.
- صفحه دانلود فارسی، ریسپانسیو، آیکون‌دار و بدون اسکرین‌شات است.
