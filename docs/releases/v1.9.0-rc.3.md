# dicodePing v1.9.0 RC3

## فارسی

RC3 بازطراحی پایداری و سرعت اسکنر Desktop است. عملیات دریافت و تست خارج از
رابط کاربری اجرا می‌شوند و فقط داده‌های دسته‌ای از مسیر Signal/Slot صف‌بندی‌شده
به رابط ارسال می‌شود.

### تغییرات اصلی

- لاگ‌های ساختاریافته و رنگی برای مراحل اتصال، تلگرام، تست، موفقیت و خطا.
- حذف تخمین زمان پایان و نمایش سرعت لحظه‌ای دانلود، تعداد کانال بر ثانیه، تعداد
  کانفیگ دریافت‌شده، نرخ تست بر ثانیه و تعداد سرور سالم.
- دریافت موازی کانال‌های رتبه ۱ و ۲ در یک صف محدود و تطبیقی، با سقف منابع برای
  جلوگیری از فریز و کرش روی سیستم‌های ضعیف‌تر.
- ارسال لاگ‌ها به‌صورت Batch و محدود کردن تاریخچه به ۱۲۰۰ خط برای جلوگیری از
  فشار بیش از حد به Event Loop و مصرف حافظه.
- پشتیبانی مستقیم از SOCKS5 محلی Aether و WARP/Usque برای دریافت کانال‌ها؛
  Xray همچنان از مسیر TUN استفاده می‌کند.
- توقف زودهنگام بعد از یافتن پنج سرور سالم، retry محدود و لغو تعاونی عملیات.
- جلوگیری از اتصال دوباره وقتی Bootstrap از قبل فعال است.
- انتقال درخواست‌های اتصال و قطع اتصال به Thread اصلی Qt با QueuedConnection.
- پاک‌سازی Worker اسکنر هنگام خروج و حذف Thread نشت‌کرده نسخه قبلی.

### ساخت ویندوز

فایل زیر را اجرا کنید:

`BUILD_RELEASE_RC3.bat`

خروجی:

`release\dicodePing-v1.9.0-rc.3-windows-x64.exe`

برای اجرای مستقیم سورس از `RUN_SOURCE_RC3.bat` استفاده کنید.

## English

RC3 rebuilds the Desktop scanner around adaptive bounded concurrency, queued
main-thread UI actions, batched highlighted logs, real throughput metrics,
Aether/WARP SOCKS5 crawling, bounded retries, cooperative cancellation, and
clean shutdown. The scanner reuses an already active bootstrap connection and
stops excess probes after five verified healthy profiles.
