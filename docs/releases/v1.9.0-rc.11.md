# dicodePing v1.9.0-rc.11

## فارسی

این نسخه مسیر شروع اسکنر را بازطراحی می‌کند تا اسکنر هیچ‌وقت به‌صورت پنهانی VPN را روشن نکند. در اولین استفاده، فقط یک بار درباره نیاز به VPN توضیح داده می‌شود. سپس برنامه به صفحه خانه می‌رود، اتصال خودکار Xray را با بهترین سرور تاییدشده برقرار می‌کند و تنها پس از عبور موفق ترافیک واقعی، اسکن را آغاز می‌کند.

| بخش | تغییر |
|---|---|
| شروع اسکن | هشدار نیاز به VPN فقط یک بار نمایش داده می‌شود |
| اتصال | اتصال و مجوز VPN فقط از صفحه خانه مدیریت می‌شود |
| ادامه خودکار | بعد از تایید اتصال، برنامه خودکار به اسکنر برمی‌گردد |
| خطا | در صورت نرسیدن به تلگرام، پیام بررسی کانفیگ، اینترنت و مجوز نمایش داده می‌شود |
| پایداری | عملیات UI، اتصال و اسکن با state machine مستقل اجرا می‌شوند؛ چرخش صفحه، لغو مجوز و شروع Foreground Service محافظت شده‌اند |
| چهار پلتفرم | روند دسکتاپ Windows/Linux/macOS و Android هماهنگ شده است |

## English

RC11 redesigns scanner startup so the scanner never silently starts a VPN. A one-time notice explains the VPN requirement. The app then returns to Home, establishes the verified automatic Xray connection, and starts scanning only after real tunneled traffic succeeds.

| Area | Change |
|---|---|
| Scanner start | The VPN requirement notice is shown once per installation |
| Connection | VPN permission and connection are owned by the Home screen |
| Automatic resume | The app returns to Scanner and starts it after connection verification |
| Failure handling | Telegram failures explain that the config, internet, and VPN permission should be checked |
| Stability | UI, connection and scanner use separate state machines; Activity recreation, VPN revoke and foreground startup are guarded |
| Platforms | The desktop flow is aligned across Windows, Linux, macOS, and Android |
