# dicodePing v1.8.0-rc.3 — Verified Scanner & Lifecycle

> Pre-release / نسخهٔ آزمایشی پیش از انتشار پایدار

## فارسی

RC3 مسیر اتصال و اسکن را سخت‌گیرانه می‌کند. موفقیت فقط زمانی ثبت می‌شود که
درخواست HTTP واقعی از داخل Xray عبور کند؛ باز بودن TCP، پاسخ ICMP یا اجرای
Process به‌تنهایی موفقیت محسوب نمی‌شود.

### تغییرات اصلی

- State machine اتصال، generation/cancellation و registry مرکزی Process و Port
- توقف کنترل‌شده، force-kill محدود، wait و پاک‌سازی هنگام خروج
- Scanner سه‌مرحله‌ای: اتصال Bootstrap، Crawl و HTTP Probe، ذخیرهٔ ساب
- توقف و ذخیرهٔ جزئی فقط برای نتایج دارای HTTP Probe موفق
- ممنوع شدن Probe در صورت شکست قطع Bootstrap (`contaminationRisk`)
- صف محدود، backpressure، concurrency سازگار با CPU/RAM، Alive Count و ETA
- ذخیرهٔ تراکنشی Source، Server، Raw، Base64 و Scanner history
- فهرست canonical کانال‌ها با Rank 1/2 و مقدار پیش‌فرض ۳
- توقف خودکار Probe پس از یافتن ۵ سرور HTTP-verified و نگهداری پنج نتیجه برتر
- برچسب محتاطانه حجمی/Cloudflare Worker/دائمی فقط از روی نشانه صریح نام یا دامنه؛ در غیر این صورت «نامشخص»
- حذف کامل Telegram proxy، Volume Detector و reconnect خودکار از Scanner
- Scanner Android با Coordinator و Foreground Service مستقل از Fragment
- Xray/AndroidLibXrayLite نسخهٔ `26.7.11`
- نصب امن و جداگانهٔ Aether `1.4.0` و Usque `4.2.1` در Windows/Linux

Manifest این Release در حالت fallback با عبارت دقیق `SHA-256 verified` منتشر

## English

RC3 makes connection and scanning fail-closed. A server is healthy only after
a real HTTP request succeeds through its Xray outbound. TCP reachability, ICMP,
a local listener, or a running process is never treated as sufficient.

Highlights:

- serialized lifecycle state machine with generation cancellation;
- central process/port ownership and bounded teardown;
- strict three-stage Scanner with bootstrap disconnect gate;
- bounded concurrent Xray HTTP probes, live alive count and robust ETA;
- Stop with verified partial save and transactional persistence;
- canonical ranked channel list shared by desktop and Android;
- Android application-owned Scanner coordinator and foreground notification;
- Xray/AndroidLibXrayLite 26.7.11;
- verified optional Aether 1.4.0 and Usque 4.2.1 desktop packs.
- a five-healthy-server target that stops new probes early and keeps the best five;
- conservative quota/Worker/persistent hints based only on explicit config metadata.

Android intentionally enables only the built-in Xray transport in RC3.
Aether, WARP and Psiphon are marked `unsupportedInThisBuild` or
`missingAuthorizedConfig`; no companion APK, Termux session, or raw executable
is downloaded.
