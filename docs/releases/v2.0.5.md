# dicodePing v2.0.5 — انتشار پایدار (APK یونورسال)

این نسخه یک مشکل اساسی را حل می‌کند: **APK اندروید روی دستگاه‌های ۳۲-بیت ARM
(armeabi-v7a) نصب نمی‌شد و به‌عنوان «ناسازگار» نمایش داده می‌شد.**

## مشکل

نسخه‌های قبلی (v2.0.0 تا v2.0.4) فقط دو ABI را در APK بسته‌بندی می‌کردند:
- `arm64-v8a` (ARM ۶۴-بیت — گوشی‌های مدرن)
- `x86_64` (Intel/AMD ۶۴-بیت — شبیه‌سازها)

این یعنی کاربرانی که گوشی‌های قدیمی‌تر با پردازنده ۳۲-بیت ARM (armeabi-v7a) داشتند،
APK را دانلود می‌کردند اما اندروید آن را «ناسازگار» نشان می‌داد و نصب نمی‌کرد.

## راه‌حل: APK یونورسال

v2.0.5 APK را به یک بسته یونورسال تبدیل می‌کند که شامل **سه ABI** است:
- `arm64-v8a` (ARM ۶۴-بیت)
- `armeabi-v7a` (ARM ۳۲-بیت — گوشی‌های قدیمی)
- `x86_64` (Intel/AMD ۶۴-بیت — شبیه‌سازها)

تغییرات فنی:

- **`build.gradle.kts`:** `abiFilters` در هر دو flavor (`standard` و `rooted`) به
  `setOf("arm64-v8a", "armeabi-v7a", "x86_64")` تغییر یافت. `expectedMachines` map
  برای بررسی ELF header های armv7 (machine code 40) به‌روزرسانی شد.
- **`prepare_bundled_cores.py`:** Aether (Rust) و Usque (Go) حالا برای هر سه ABI
  کامپایل می‌شوند. Rust target `armv7-linux-androideabi` اضافه شد و Go `GOARCH=arm`
  با clang prefix `armv7a-linux-androideabi` برای CGO استفاده می‌شود.
- **`release.yml`:** Rust toolchain حالا `armv7-linux-androideabi` target را هم
  نصب می‌کند. بررسی APK به‌جای ممنوع کردن ۳۲-بیت، حالا به‌طور صریح هر سه ABI را
  verify می‌کند (`for abi in arm64-v8a armeabi-v7a x86_64`). فقط `x86` (Intel
  ۳۲-بیت) همچنان ممنوع است چون ساخته نمی‌شود.
- **`verify_apk_cores.py`:** `ABIS` map به‌روزرسانی شد تا `armeabi-v7a` با ELF
  machine code 40 را هم بررسی کند.
- **`validate_project.py`:** بررسی ABI به‌روزرسانی شد تا مجموعه سه-ABI جدید را
  قبول کند.

## اندازه APK

APK حدود ۱۰-۱۵ مگابایت بزرگ‌تر می‌شود چون کتابخانه‌های native (libgojni، libaether،
libusque) برای هر سه ABI بسته‌بندی می‌شوند. این یک به‌رسمیت‌شناسی طبیعی برای
پشتیبانی یونورسال است.

## تغییرات فنی دیگر

- `versionCode` اندروید از ۶۰ به ۶۱ افزایش یافت.
- `RELEASE_VERSION` از `2.0.4` به `2.0.5`.
- `tools/validate_v204_stable.py` به `tools/validate_v205_stable.py` تغییر نام داد.
- `tests/test_v204_stable*.py` به `tests/test_v205_stable*.py` تغییر نام دادند.
