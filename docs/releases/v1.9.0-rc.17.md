# dicodePing v1.9.0-rc.17

RC17 focuses on fast scanner persistence, understandable server metadata, and a more reliable Aether integration.

## Highlights

- Scanner SUBs are saved with resolved location metadata instead of waiting for a later refresh.
- Server cards show a conservative security estimate from 0 to 100.
- Optimized resource usage is enabled by default; professional mode increases bounded concurrency.
- Android Aether uses the QW-AI-Code/Aether mobile build pipeline.
- Desktop lifecycle and cancellation were aligned with the robust state-machine patterns reviewed in Aether-GUI.
- Release includes Windows, Linux, macOS and Android artifacts plus source, checksums and SBOM.

The security score is informational and does not guarantee the trustworthiness of a third-party server.
## Release pipeline hotfix

- Fixed Android Kotlin compilation in `ScannerCoordinator`: runtime tuning now reads `repo.settings.resourceMode` from the repository field actually declared by the class.
- Added a source-reference validator to local preflight, Android build scripts, and GitHub Actions so this regression is rejected before the expensive native-core build.
- Added retry/backoff handling for transient GitHub CLI and Pages API failures such as `TLS handshake timeout`.
