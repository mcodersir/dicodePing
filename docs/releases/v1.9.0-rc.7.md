# dicodePing v1.9.0-rc.7

## فارسی

RC7 یک نسخه اصلاحی برای پایداری اتصال خودکار، سنجش سریع‌تر هنگام شروع برنامه و بازطراحی منوی کناری است.

| بخش | تغییرات |
|---|---|
| اتصال خودکار | خطای مقایسه `ConfigQualityResult` رفع شد و دکمه اتصال داشبورد در صورت نبود نتیجه آماده، بهترین سرور را با تست واقعی Xray انتخاب می‌کند. |
| اسپلش و پینگ | هنگام شروع برنامه، از هر منبع ۳۰٪ سرورها به‌صورت واقعی سنجیده می‌شوند. بعد از باز شدن رابط، کاربر می‌تواند سنجش کامل همه سرورها را اجرا کند. |
| منوی کناری | جای منو در فارسی به‌صورت صریح در سمت راست و در انگلیسی در سمت چپ تثبیت شد. متن و آیکون‌ها در حالت باز به لبه درست تراز می‌شوند و حالت جمع‌شده مینیمال‌تر است. |
| تنظیمات | صفحه تنظیمات و بخش روش اتصال تمام ارتفاع قابل استفاده را می‌گیرند و آیکون بازشدن فهرست‌های کشویی واضح شده است. |
| DNS امن | قابلیت DoH در نصب تازه به‌صورت پیش‌فرض غیرفعال است. |
| پایداری | انتخاب بهترین سرور در Thread جدا انجام می‌شود تا رابط کاربری هنگام تست واقعی فریز نشود. |

### خروجی‌ها

- Windows x64: فایل EXE قابل حمل
- Linux x86_64: آرشیو `tar.gz`
- macOS: دو فایل DMG برای Apple Silicon و Intel
- Android: فایل APK امضاشده

## English

RC7 is a corrective release focused on reliable automatic connection, faster startup testing, and a stable cross-platform sidebar layout.

| Area | Changes |
|---|---|
| Automatic connection | Fixed the `ConfigQualityResult` comparison error. When no pre-verified winner exists, the dashboard now selects the best server using real Xray HTTP tunnel tests. |
| Splash and latency | Startup tests a deterministic 30% sample from every subscription. After the interface opens, users are offered a full test of all saved servers. |
| Sidebar | Persian navigation is explicitly placed on the right and English navigation on the left. Expanded labels and icons align to the correct edge, while collapsed mode stays compact. |
| Settings | Settings and connection-method pages now fill the available height, and combo-box dropdown indicators are visible. |
| Secure DNS | DoH is disabled by default for fresh installations. |
| Responsiveness | Best-server selection runs in a background worker so the interface remains responsive during real tests. |

### Release assets

- Portable Windows x64 EXE
- Linux x86_64 `tar.gz`
- macOS DMG for Apple Silicon and Intel
- Signed Android APK
