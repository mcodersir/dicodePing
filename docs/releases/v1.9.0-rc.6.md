# dicodePing v1.9.0-rc.6

## فارسی

RC6 روی سنجش واقعی کانفیگ‌ها، آماده‌سازی کامل پیش از نمایش رابط و اصلاح چیدمان راست‌به‌چپ تمرکز دارد.

| بخش | تغییر اصلی |
|---|---|
| اسکنر | سنجش واقعی هر کانفیگ با Xray و درخواست HTTP عبوری؛ سه تلاش، حداقل دو پاسخ موفق و انتخاب میانه تأخیر |
| fallback | برای فرمت‌های پشتیبانی‌نشده فقط بررسی TCP محدود و با برچسب واضح `tcp-fallback` انجام می‌شود |
| اسپلش | دریافت منابع، بررسی تغییرات، تست تأخیر، مکان‌یابی و بررسی نسخه برنامه پیش از نمایش رابط انجام می‌شود |
| رابط اسکنر | لاگ‌ها به سه نمای «همه»، «تلگرام» و «تست واقعی» تفکیک شده و شاخص‌های دریافت، تست و سرور سالم مستقل هستند |
| منوی کناری | در فارسی آیکون و متن از لبه راست و در انگلیسی از لبه چپ تراز می‌شوند |
| Android | تست اسکنر سه‌مرحله‌ای با هسته Native، ذخیره یک منبع ثابت `SUB` و اجرای کامل آماده‌سازی در Splash |
| انتشار | خروجی Windows، Linux، macOS Intel/Apple Silicon و APK امضاشده Android با یک اسکریپت Deploy |

### نکات تست

- نتیجه «سالم» فقط با عبور واقعی HTTP از همان outbound پذیرفته می‌شود.
- نمونه‌های تأخیر و تعداد موفقیت‌ها در لاگ زنده ثبت می‌شوند.
- هر اجرای اسکنر همان منبع `SUB` را جایگزین می‌کند؛ ساب‌های تکراری ساخته نمی‌شوند.

## English

RC6 focuses on real configuration verification, complete pre-UI startup preparation, and corrected RTL navigation.

| Area | Main change |
|---|---|
| Scanner | Each supported config is verified through Xray with real tunneled HTTP traffic; three attempts, at least two successes, and median latency |
| Fallback | Unsupported formats use a bounded TCP check explicitly labeled `tcp-fallback` |
| Splash startup | Source updates, downloads, latency tests, geolocation, and application update checks finish before the main UI opens |
| Scanner UI | Live logs are split into All, Telegram, and Real tests; download, testing, and healthy-server metrics are independent |
| Sidebar | Persian navigation aligns icons and text to the right edge; English aligns them to the left edge |
| Android | Three-sample native-core scanner tests, one stable `SUB` source, and full startup preparation inside Splash |
| Distribution | One deploy script produces Windows, Linux, macOS Intel/Apple Silicon, and signed Android APK assets |

### Testing notes

- A server is accepted only after real HTTP traffic succeeds through its exact outbound.
- Live logs expose samples, success counts, tester type, and median latency.
- Every scan atomically replaces the single `SUB` source instead of creating duplicate subscriptions.
