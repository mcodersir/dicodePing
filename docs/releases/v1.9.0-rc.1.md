# dicodePing v1.9.0 RC1

## فارسی

این نسخه اولین انتشار چهارسکویی dicodePing برای Windows، Linux، macOS و
Android است.

- Xray `26.7.11` هسته پیش‌فرض و تنها هسته Scanner است.
- Aether `1.4.0` و Usque `4.2.1` پس از بررسی SHA-256 در بسته‌های Desktop
  قرار می‌گیرند و دانلود جداگانه داخل برنامه حذف شده است.
- macOS Apple Silicon به Pipeline رسمی Build و Pre-release اضافه شد.
- صفحه تنظیمات دارای پروفایل مستقل Aether/WARP برای Protocol، Ironclad،
  HTTP/3 با fallback به HTTP/2، مصرف منابع و Quick Reconnect است.
- DNS امن مبتنی بر DNS-over-HTTPS به Desktop و Android اضافه شد. این
  قابلیت از توضیح و معماری Intra الهام گرفته، اما از کد Intra کپی نمی‌کند.
- Xray همچنان فقط پس از HTTP واقعی عبوری Connected می‌شود و Scanner فقط
  نتیجه دارای HTTP Probe موفق را ذخیره می‌کند.
- مجوزها، منشأ Binaryها و پروژه‌های مرجع در `THIRD_PARTY_NOTICES.md` و
  SBOM ثبت شده‌اند.

### محدودیت Android

فایل‌های Android منتشرشده Aether 1.4.0 برای Termux هستند و API داخلی
سازگار با Android `VpnService` ارائه نمی‌کنند. به همین دلیل RC1 آن‌ها را
به‌عنوان اتصال جعلی فعال نمی‌کند. Android از `libv2ray 26.7.11` داخلی و
DoH واقعی استفاده می‌کند. Aether/WARP تا ارائه Library قابل جاسازی با
`unsupportedInThisBuild` نمایش داده می‌شوند.

## English

This is the first four-platform dicodePing prerelease for Windows, Linux,
macOS, and Android.

- Xray `26.7.11` remains the default core and the Scanner's only transport.
- Aether `1.4.0` and Usque `4.2.1` are SHA-256 verified and bundled in every
  Desktop package; a separate in-app core download is no longer required.
- macOS Apple Silicon is built and published by the release pipeline.
- Independent Aether/WARP profile controls cover protocol, Ironclad scanning,
  HTTP/3 with HTTP/2 fallback, resource tuning, and quick reconnect.
- Secure DNS using DNS-over-HTTPS is available on Desktop and Android. It is
  inspired by Intra's documented purpose but uses Xray's own DoH client.
- Xray reaches Connected only after a real HTTP request through the selected
  outbound. Scanner results still require a successful Xray HTTP probe.
- Binary provenance, licenses, design references, and source obligations are
  recorded in `THIRD_PARTY_NOTICES.md` and the generated SPDX SBOM.

### Android limitation

Aether 1.4.0's published Android archives target Termux and do not expose an
embeddable `VpnService` library API. RC1 therefore does not present them as a
fake working transport. Android ships the supported embedded
`libv2ray 26.7.11` transport and real DoH; Aether/WARP remain explicitly
`unsupportedInThisBuild` until a same-package library adapter exists.
