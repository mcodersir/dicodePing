# dicodePing v1.9.0 RC2

## فارسی

RC2 یک انتشار اصلاحی برای اتصال Desktop است و خطای اجرای Xray، فعال‌سازی
WARP/Aether و بازخورد رابط کاربری را هدف می‌گیرد.

### اصلاحات اصلی

- خطای `XrayManager.start() got an unexpected keyword argument 'core_options'`
  برطرف شد. قرارداد مشترک اتصال اکنون بدون ارسال گزینه‌های مخصوص هسته‌های
  جایگزین به Xray کار می‌کند.
- اجرای Aether با قرارداد واقعی CLI نسخه 1.4.0 اصلاح شد: `--masque`، `--wg`،
  `--gool`، `--scan`، `--noize` و Quick Reconnect. گزینه‌های نامعتبر
  `--wireguard` و `--perf` حذف شدند.
- حالت پیش‌فرض اسکن Aether از Ironclad به Balanced تغییر کرد تا اتصال اولیه
  سریع‌تر باشد؛ Ironclad همچنان از تنظیمات قابل انتخاب است.
- fallback از HTTP/3/QUIC به HTTP/2 فقط برای MASQUE اجرا می‌شود و برای
  WireGuard/gool دیگر یک تلاش تکراری و بی‌اثر انجام نمی‌شود.
- WARP/Usque با ثبت‌نام غیرتعاملی، ذخیره اتمیک `config.json`، بررسی کامل بودن
  کلیدها و timeout محدود فعال می‌شود.
- دانلود، ثبت WARP، فعال‌سازی هسته و اتصال همگی وضعیت مرحله‌ای و Progress
  قابل مشاهده دارند و UI هنگام ثبت WARP قفل نمی‌شود.
- انتخاب هسته و پروفایل Aether پس از فعال‌سازی در تنظیمات کاربر ذخیره می‌شود.
- فایل هویت و مسیر سالم قبلی Aether در پوشه دائمی داده‌های کاربر نگه‌داری می‌شود؛
  بنابراین Quick Reconnect بعد از بستن برنامه از بین نمی‌رود.
- Pipeline و metadata نسخه به `1.9.0-rc.2` ارتقا یافت و Builder ویندوز وجود
  Xray، Aether و Usque را پیش از ساخت Release الزامی می‌کند.

### ساخت ویندوز

فایل `BUILD_RELEASE_RC2.bat` را اجرا کنید. خروجی نهایی در مسیر زیر ساخته
می‌شود:

`release\dicodePing-v1.9.0-rc.2-windows-x64.exe`

## English

RC2 fixes the shared Xray call contract, aligns Aether 1.4.0 and Usque 4.2.1
commands with their upstream CLIs, makes WARP registration atomic and
non-blocking, persists core settings, adds visible connection progress, and
moves the default Aether scan from Ironclad to Balanced for faster startup.
