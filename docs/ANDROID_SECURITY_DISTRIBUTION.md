# Android APK signing — RC4

Only the standard Android release APK requires the owner's release keystore.

Required environment variables:

```bat
set ANDROID_KEYSTORE_PATH=C:\secure\dicodePing-release.jks
set ANDROID_KEYSTORE_PASSWORD=...
set ANDROID_KEY_ALIAS=...
set ANDROID_KEY_PASSWORD=...
```

Run:

```bat
BUILD_SIGNED_APK_RC4.bat
```

Output:

```text
dicodePing_android\release\dicodePing-v1.9.0-rc.4-android.apk
```

No AAB is generated by this release script.
