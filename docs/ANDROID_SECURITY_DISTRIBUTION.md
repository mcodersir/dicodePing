# Android secure distribution — Version 3

The Android Version 3 release is produced by `dicodePing_android/build_apk.sh` or `build_apk.bat`. The release path is intentionally single-runtime and fails closed if the pinned native runtime, ABI coverage, signing inputs, lint, or unit tests are invalid.

## Signing

Keep the JKS outside the repository and provide only these environment variables:

```text
ANDROID_KEYSTORE_PATH
ANDROID_KEYSTORE_PASSWORD
ANDROID_KEY_ALIAS
ANDROID_KEY_PASSWORD
```

GitHub Actions materializes the keystore from the `ANDROID_KEYSTORE_BASE64` secret into the runner temporary directory. Secrets are not written into project files or release metadata.

## Runtime verification

The build downloads the pinned Android runtime only when the local copy is absent or has the wrong SHA-256, then verifies its digest before Gradle runs. The completed APK is checked again to ensure native libraries for `arm64-v8a`, `armeabi-v7a`, and `x86_64` are present.
