# دیکدپینگ ۴.۹.۹۹۱ — اصلاح مسیر نشست روباه

- 🔑 بازیابی HTTP/2 در مسیر واقعی ورود مرورگری، بررسی تأیید نشست و تمدید توکن فعال شد؛ هدر identity حفظ می‌شود.
- 🔄 درخواست تمدید، همان مجوز و refresh token را استفاده می‌کند؛ توکن منقضی یا ردشده معتبر فرض نمی‌شود.
- 📊 تازه‌سازی سهمیه از مسیر بومی حساب انجام می‌شود و به ثبت مجدد حساب وابسته نیست.
- 🌐 متن‌های فنی مربوط به نام هسته از صفحهٔ دانلود حذف شدند.
- 📱 کد داخلی نصب بالاتر از ۴.۹.۹۹ است؛ برنامه را حذف نکنید و APK را روی نصب فعلی نصب کنید.

این تغییر، نقص مسیر اجرایی برنامه را پوشش می‌دهد. آزمون‌های خودکار با پاسخ کنترل‌شده، جای تأیید ورود زنده روی شبکهٔ کاربران را نمی‌گیرند.
