# Version 3 test matrix

Release validation covers:

- startup and runtime initialization
- authoritative subscription fetch/refresh
- profile normalization/import
- profile list and selection
- connection/disconnection/reconnection
- switching selected profiles
- real latency testing
- invalid profile handling
- runtime process crash detection and restart path
- routing, DNS, TUN and system proxy settings
- statistics and logs
- settings persistence in the Version 3 namespace
- clean shutdown
- Windows x64 packaging
- Linux x86_64 packaging
- macOS arm64/x86_64 packaging
- Android universal packaging and native ABI verification
