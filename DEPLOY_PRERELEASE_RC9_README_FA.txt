انتشار خودکار dicodePing v1.9.0 RC9
====================================

1. ZIP را در یک مسیر کوتاه Extract کنید.
2. فایل DEPLOY_PRERELEASE_RC9.bat را اجرا کنید.
3. اسکریپت با Git Credential Manager وارد GitHub می‌شود، سورس را روی main پوش می‌کند،
   تگ v1.9.0-rc.9 را ایجاد یا به Commit جدید منتقل می‌کند و منتظر پایان GitHub Actions می‌ماند.
4. پس از موفقیت Windows، Linux، macOS و Android، صفحه Pre-release باز می‌شود.

هیچ توکن GitHub داخل فایل‌ها ذخیره نشده است.
