# dicodePing 1.9.0 RC10

RC10 focuses on the Telegram scanner and connection-state correctness across Windows, Linux, macOS and Android.

## Release

Extract the source archive and run:

```bat
DEPLOY_PRERELEASE_RC10.bat
```

The script pushes the fixed source, creates or updates `v1.9.0-rc.10`, waits for the multi-platform GitHub Actions workflow and opens the pre-release page.

Expected assets:

- `dicodePing-v1.9.0-rc.10-windows-x64.exe`
- `dicodePing-v1.9.0-rc.10-linux-x86_64.tar.gz`
- `dicodePing-v1.9.0-rc.10-macos-arm64.dmg`
- `dicodePing-v1.9.0-rc.10-macos-x86_64.dmg`
- `dicodePing-v1.9.0-rc.10-android.apk`

Bilingual notes: `docs/releases/v1.9.0-rc.10.md`.
