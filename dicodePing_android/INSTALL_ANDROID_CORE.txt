dicodePing Android — Version 3 runtime preparation

From the repository root run:

  PREPARE_V3_RUNTIME.bat

Or directly:

  python tools\fetch_runtime_assets.py --android

The helper retrieves the pinned Android Xray runtime and verifies SHA-256 before placing it in:

  dicodePing_android/local-maven/ir/dicode/local/libv2ray/26.7.11/libv2ray-26.7.11.aar

Expected SHA-256:
  0c79bb52dc4329aaa266601e56ce4f0cc756b43f97a43dccd08d4a4bfc9aa352

Release builds fail closed when the runtime is absent, corrupted, missing classes.jar, or missing required native ABIs.
