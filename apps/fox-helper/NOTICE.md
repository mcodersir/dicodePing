DicodePing Fox 5.0.0 is based on armanlife/arman-vpn-client v1.0.14, commit fe76e2c68e412e938032536121c1f975dedcbf32 (GPL-3.0). Imported auth, OAuth PKCE fallback, control-plane TLS/DNS, Guardian, HTTP/2 transport, SOCKS and renewal/recovery code is recorded in UPSTREAM.json. DicodePing integrates this core with its encrypted account vault and private stdio protocol. Source modifications and corresponding source are published in the release repository. Earlier protocol work derived from FoxyVPN (MIT) remains attributed by the accompanying license. This is an unofficial client; Mozilla account verification and service limits still apply.
