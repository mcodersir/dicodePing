DicodePing Fox 4.9.99 is based on armanlife/arman-vpn-client v1.0.13, commit bb9c3e306841dd9df03c85bba4cb716e4c7173c6 (GPL-3.0). Imported auth, OAuth PKCE fallback, control-plane TLS/DNS, Guardian, HTTP/2 transport, SOCKS and renewal/recovery code is recorded in UPSTREAM.json. DicodePing integrates this core with its encrypted account vault and private stdio protocol. Source modifications and corresponding source are published in the release repository. Earlier protocol work derived from FoxyVPN (MIT) remains attributed by the accompanying license. This is an unofficial client; Mozilla account verification and service limits still apply.
