DicodePing Fox 5.0.3 is based on armanlife/arman-vpn-client v1.0.18, commit 405f412fa28c0f56bd2a0d85617558e7216d6b05 (GPL-3.0). Imported auth, OAuth PKCE fallback, control-plane TLS/DNS, Guardian, HTTP/2 transport, SOCKS and renewal/recovery code is recorded in UPSTREAM.json. DicodePing integrates this core with its encrypted account vault and private stdio protocol. Source modifications and corresponding source are published in the release repository. Earlier protocol work derived from FoxyVPN (MIT) remains attributed by the accompanying license. This is an unofficial client; Mozilla account verification and service limits still apply.

Control-plane fetch metadata follows PR #79 (head b1168ff72f654c4733c692c111fdc65c41e99b28); Mozilla Origin/Referer headers are scoped to exact Mozilla domains and their subdomains.
